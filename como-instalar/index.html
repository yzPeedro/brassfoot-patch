Como instalar o Brasfoot Patch V4

O patch é gratuito e independente. É necessário possuir uma instalação legítima do Brasfoot 22–23 para Windows.

1. Baixe a versão correta

A atualização v2026.3.4 é distribuída como um instalador Brasfoot-Patch-2026-Setup-v2026.3.4.exe. O botão principal do site só fica disponível após a publicação e conferência de integridade do arquivo no GitHub Releases.

2. Selecione a pasta do Brasfoot original

Abra o instalador e escolha a pasta onde o jogo já está instalado, por exemplo C:\Brasfoot22-23. Não precisa criar outra pasta ou substituir atalhos manualmente. Feche o jogo antes de aplicar a atualização.

3. Backup integral antes de modificar

O instalador copia a instalação existente para um backup separado, incluindo saves, equipes, configurações e personalizações. Se o backup falhar, a instalação deve ser interrompida sem substituir arquivos.

4. Atualização V4 no mesmo caminho

O patch aplica os arquivos da V4 na instalação existente, com seletor de 2026 e reorganização das Séries A/B/C. O caminho de bf22-23.exe não muda e os atalhos existentes continuam apontando para o jogo. A barra informa as etapas e o instalador registra um relatório.

5. Confirme e abra o jogo

Ao concluir, o instalador apresenta a confirmação e o caminho do backup. Abra o Brasfoot e teste em uma nova carreira; a compatibilidade de carreiras antigas e temporadas futuras não é garantida apenas pela preservação dos arquivos.

6. Como desfazer o patch

Abra o instalador e selecione Restaurar Brasfoot original. A restauração usa o backup criado antes da atualização. Recomenda-se guardar uma cópia dos saves recentes antes de restaurar.

Limitações conhecidas

Os elencos de B/C não devem ser considerados integralmente atualizados para 2026. A validação completa de uma temporada, progressão de ano, camisas e escudos ainda exige testes adicionais.
