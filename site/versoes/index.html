O que acompanha o download.

Ferramentas para atualizar o Brasfoot, conferir os arquivos da instalação, criar backup e restaurar o conteúdo. O pacote preserva a origem dos dados e oferece arquivos específicos para cada sistema e arquitetura.

No site, o explorador mostra os jogadores dos 957 clubes do pacote, com as ligas e divisões da América do Sul. A cobertura registra os 622 elencos atualizados, a fonte de cada um e as fontes parciais preservadas.

Atualizações pelo próprio hub.

Quem já tem o hub não precisa voltar aqui: a cada abertura, ele confere esta mesma versão no GitHub e mostra o aviso Nova versão do patch, com Ver novidades e Atualizar. Quando o próprio hub muda, aparece Nova versão do instalador, com o que mudou e a atualização em um clique.

Cada versão publica o hub, um pacote -bundle.zip com as instruções de atualização e um arquivo release.json com as notas e o SHA-256 de cada arquivo. O hub só instala o que confere com esses números.
