## Um hub só, sempre atualizado

- O hub não carrega mais o patch dentro dele: a cada abertura ele confere no GitHub a versão mais recente e baixa só o que precisa.
- Quando sai uma versão nova do patch, aparece o aviso **Nova versão do patch** com o botão **Ver novidades**, que mostra o que mudou, e o botão **Atualizar**.
- Quando sai um instalador novo, aparece o aviso **Nova versão do instalador** com o que mudou e o botão **Atualizar instalador**. Ele se atualiza e reabre sozinho.
- Na primeira vez, o hub se instala em uma pasta fixa do seu usuário e cria atalhos no Menu Iniciar e na área de trabalho. Dá para removê-lo em Configurações > Aplicativos.
- Todo download é conferido pelo SHA-256 publicado na release antes de qualquer arquivo do jogo ser alterado.
- Sem internet, o hub usa a última versão já baixada neste computador; ainda dá para jogar e restaurar backups.
