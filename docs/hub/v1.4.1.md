## Abertura

- O ícone do Mega Patch aparece pulsando assim que o hub é aberto, mesmo quando o Windows ainda está carregando o WebView2; a janela não fica mais branca ou preta.
- A animação acompanha a taxa de atualização do monitor e passa para a tela do hub sem salto.
- Com as animações do Windows desligadas, o ícone só esmaece.
