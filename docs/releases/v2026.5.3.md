# Brasfoot Mega Patch 2026.5.3

Esta versão estreia o hub único e corrige lances do campo animado.

## Um hub só, sempre atualizado

- Baixe o hub uma vez. Na primeira abertura ele se instala no seu usuário, com atalhos no Menu Iniciar e na área de trabalho.
- A cada abertura, o hub confere no GitHub a versão mais recente do patch. Quando há novidade, aparece o aviso **Nova versão do patch** com **Ver novidades** e **Atualizar**.
- Quando o próprio hub ganha uma versão nova, aparece **Nova versão do instalador**, com o que mudou e a atualização em um clique.
- Todo download é conferido pelo SHA-256 publicado na release antes de qualquer arquivo do jogo ser alterado. Sem internet, o hub usa a última versão já baixada.
- Quem usa uma versão anterior do instalador precisa baixar o hub novo uma única vez.

## Campo animado

- Depois de um gol, a saída de bola só acontece com todos os jogadores de volta às posições.
- Faltas só são marcadas com contato: o infrator corre até o jogador com a bola e comete a falta.
- Gol de falta nasce de uma jogada no campo de ataque, no ponto onde a falta aconteceu.
- Cartões amarelos e vermelhos só para quem participou do lance.
- Jogador substituído com a bola toca para um companheiro antes de sair.

## Suas carreiras

O patch continua sem alterar carreiras salvas: cada save guarda o próprio mundo, com times, jogadores e competições, e o jogo não relê os arquivos de time ao carregar. Os elencos novos valem para carreiras novas.

## Dados

Os elencos e a cobertura são os mesmos da 2026.5.2.

Nenhuma suíte, teste de navegador ou gameplay foi executado, conforme decisão do proprietário. A compilação, os hashes, as receitas delta e a publicação foram conferidos separadamente; os manifestos mantêm `compatibilityVerifiedInGame=false` e `gameplayVerified=false`.
