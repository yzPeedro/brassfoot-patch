# Brassfoot Patch 2026 — Versão 2026.0.2

**Primeira versão pública experimental**, para Brasfoot 2022–2023 no Windows 64 bits.

## O que há nesta versão

- Atualização de **20 equipes brasileiras**, totalizando **730 jogadores**.
- Elencos derivados da coleta feita em 25/10/2026 e associados aos arquivos do Brasfoot instalados no computador.
- Instalador gráfico offline: detecta instalação, valida assinaturas SHA-256 e pede confirmação.
- Backup dos arquivos alterados e recurso **Desfazer patch**; saves `.s22`, `.sbck`, opções e demais arquivos pessoais não são alvo da substituição.
- Exige uma instalação original compatível do Brasfoot: distribui **somente instruções diferenciais**, não inclui arquivos `.ban` completos do jogo.
- Uma instalação anterior foi testada e aprovada no Brasfoot pelo mantenedor; a versão distribuível recompõe os mesmos 20 arquivos byte a byte nos testes automatizados.

## Limitações conhecidas — leia antes de instalar

- **713 jogadores têm atributos e/ou características estimados**, que não representam classificação oficial.
- **15 dos 745 atletas coletados não foram incluídos** devido ao limite atual de 40 atletas por equipe do gerador.
- A coleta não confirma cada atributo, nacionalidade, posição detalhada ou qualidade dos plantéis como fato de 2026.
- Esta versão deve ser considerada experimental quanto à fidelidade esportiva dos elencos.
- Instalações modificadas, versões não reconhecidas ou hashes originais diferentes serão **recusados**, sem forçar substituição.
- Recomenda-se iniciar uma **nova carreira**; saves antigos podem continuar intactos, mas a compatibilidade de sua lógica com elencos modificados não foi comprovada.
- O instalador distribuível usa empacotamento diferencial distinto do executável privado aprovado; testes automatizados passaram, mas um teste adicional da interface no Windows é aconselhável.

## Instalação

1. Faça uma cópia de segurança da carreira e **feche o Brasfoot**.
2. Baixe e execute `Brassfoot-Patch-2026-Setup.exe` (Windows 64 bits).
3. Confirme a pasta do jogo (normalmente `C:\Brasfoot22-23`).
4. Clique em **VERIFICAR E INSTALAR PATCH**.
5. Confirme o aviso e, após finalizar, abra o Brasfoot em uma nova carreira.

O instalador funciona offline e não exige Java, Python ou credenciais de API. O botão **SÓ VERIFICAR** permite conferir a instalação sem alterá-la. O botão **DESFAZER PATCH** só fica disponível se existir backup reconhecido e íntegro dessa instalação.
